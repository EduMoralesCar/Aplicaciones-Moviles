# 🛒 Proyecto 10 - Sistema de Ventas con Drawer Navigation

Aplicación móvil desarrollada en React Native que implementa una interfaz de Acceso (Login) seguro y un Menú Lateral (Drawer) para navegar entre distintos módulos del sistema.

## 🚀 Requisitos Previos

Antes de ejecutar el proyecto, es necesario instalar las librerías oficiales de **React Navigation** y los íconos de Expo.

### 1. Crear el proyecto base
```bash
npx create-expo-app proyecto10-app --template blank
cd proyecto10-app
```

### 2. Instalación de Dependencias

Abre tu terminal y ejecuta el siguiente comando para instalar todos los paquetes necesarios de navegación y gestos:


```bash
npx expo install @react-navigation/native @react-navigation/native-stack @react-navigation/drawer react-native-screens react-native-safe-area-context react-native-gesture-handler react-native-reanimated @expo/vector-icons
```
### 3.📱 Ejecución del Proyecto

Basta con ejecutar el siguiente comando para iniciar el servidor de desarrollo:

```bash
npx expo start -c
```
